# Simple object mode

The shape a simple object draws.

| Value | Name | Meaning |
| --- | --- | --- |
| `"line"` | line | A straight line from the first point to the second. |
| `"rectangle"` | rectangle | A rectangle with the two points as opposite corners. |
| `"ellipse"` | ellipse | An ellipse inscribed in the rectangle with the two points as opposite corners. |
