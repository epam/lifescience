# Radical

Radical state, encoded as the `RAD` property of MOL files.

| Value | Name | Meaning |
| --- | --- | --- |
| `0` | none | No radical. The default; writers omit the key. |
| `1` | singlet | Singlet: a diradical whose two electrons are paired. |
| `2` | doublet | Doublet: a monoradical with one unpaired electron. |
| `3` | triplet | Triplet: a diradical with two unpaired electrons. |
