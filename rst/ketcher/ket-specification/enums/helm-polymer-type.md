# HELM polymer type

The HELM polymer type a monomer belongs to.

| Value | Name | Meaning |
| --- | --- | --- |
| `"PEPTIDE"` | peptide | A monomer of a peptide: an amino acid. |
| `"RNA"` | nucleic acid | A monomer of a nucleic acid: a sugar, base, phosphate or whole nucleotide. |
| `"CHEM"` | chemical | Any other monomer. |
