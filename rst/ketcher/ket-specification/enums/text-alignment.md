# Text alignment

Horizontal alignment of the paragraphs of a text object within its bounding box.

| Value | Name | Meaning |
| --- | --- | --- |
| `"left"` |  | Aligned to the left edge of the bounding box. |
| `"center"` |  | Centred in the bounding box. |
| `"right"` |  | Aligned to the right edge of the bounding box. |
