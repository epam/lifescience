# Atom CIP descriptor

Cahn–Ingold–Prelog descriptor of a stereocentre.

| Value | Name | Meaning |
| --- | --- | --- |
| `"R"` |  | R configuration. |
| `"S"` |  | S configuration. |
| `"r"` |  | Pseudo-asymmetric r configuration. |
| `"s"` |  | Pseudo-asymmetric s configuration. |
