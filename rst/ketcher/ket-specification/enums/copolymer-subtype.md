# Copolymer subtype

How the different units of a copolymer follow each other, as in the `SST` property of MOL files.

| Value | Name | Meaning |
| --- | --- | --- |
| `"ALT"` | alternating | The kinds of unit alternate regularly. |
| `"RAN"` | random | The kinds of unit follow each other in no fixed order. |
| `"BLO"` | block | Units of the same kind form blocks. |
