# Connection type

The kind of bond a connection makes.

| Value | Name | Meaning |
| --- | --- | --- |
| `"single"` | single | A covalent single bond between two attachment points, or between an attachment point and an atom. |
| `"hydrogen"` | hydrogen | A hydrogen bond between two monomers, as between the bases of a base pair; it uses no attachment point. |
