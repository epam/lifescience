# Enumerations

An enumeration lists the values a key takes and what each value means. Each attribute that takes its values from an enumeration links to its page. Where a value follows a code of MOL or RXN files, the page names the code.

| Enumeration | What it encodes |
| --- | --- |
| [Radical](radical.md) | the radical state of an atom |
| [Bond type](bond-type.md) | the order of a bond, or the class of bonds a query bond matches |
| [Bond stereo](bond-stereo.md) | how a bond shows the stereochemistry at its first atom |
| [Bond topology](bond-topology.md) | whether a query bond lies in a ring or in a chain |
| [Reacting center](reacting-center.md) | what happens to a bond in a reaction |
| [Inversion / retention](inv-ret.md) | the stereo outcome of a reaction at a mapped atom |
| [Atom CIP descriptor](atom-cip.md) | the Cahn–Ingold–Prelog descriptor of a stereocentre |
| [Ring bond count](ring-bond-count.md) | a query constraint on the number of ring bonds of an atom |
| [Substitution count](substitution-count.md) | a query constraint on the number of non-hydrogen neighbours of an atom |
| [Query hydrogen count](h-count.md) | a query constraint on the hydrogen count of an atom |
| [R-group attachment point flags](rgroup-attachment-bits.md) | whether an atom of an R-group member is its first or second attachment point, or both |
| [Text alignment](text-alignment.md) | the horizontal alignment of the paragraphs of a text |
| [Arrow mode](arrow-mode.md) | how an arrow is drawn, and what a reaction arrow means |
| [Simple object mode](simple-object-mode.md) | the shape a simple object draws |
| [Monomer class](monomer-class.md) | the chemical role of a monomer |
| [HELM polymer type](helm-polymer-type.md) | the HELM polymer type a monomer belongs to |
| [Ambiguous monomer subtype](ambiguous-monomer-subtype.md) | whether an ambiguous monomer is one of its options or a mixture of them |
| [Connection type](connection-type.md) | the kind of bond a connection makes |
| [Monomer shape type](monomer-shape-type.md) | the symbol a monomer shape draws |
| [S-group connectivity](sgroup-connectivity.md) | how the consecutive units of a polymer are joined |
| [Copolymer subtype](copolymer-subtype.md) | how the different units of a copolymer follow each other |
| [Data S-group context](data-sgroup-context.md) | what the data of a data S-group describes |
