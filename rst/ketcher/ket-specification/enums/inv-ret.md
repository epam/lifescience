# Inversion / retention

Stereo outcome of a reaction at a mapped atom, encoded as the `INVRET` property of MOL files.

| Value | Name | Meaning |
| --- | --- | --- |
| `0` | unspecified | Not specified. The default; writers omit the key. |
| `1` | inverts | The reaction inverts the configuration of the atom. |
| `2` | retains | The reaction retains the configuration of the atom. |
