# Changelog

- **2026-11-13** (draft): An object that is only the value of one key of one object is described under that key: the header in Document, the document annotation in Root, the attachment points of a Superatom, the options of an Ambiguous monomer template, the R-group logic in R-group and the transformation in Monomer. The format is unchanged.
- **2026-10-29** (draft): Versioning: what a version number means, when each part changes, the version history, and how writers and readers use `ket_version`. What a version after 1.0.0 introduced is marked with Since. Every chapter introduces its pages and links each of them.
- **2026-10-24** (draft): Every object of the format described: bonds, R-group labels, atom lists, stereo flag positions, properties and highlights; S-groups; R-groups; reactions, arrows, pluses, simple objects and images; KET 1.0 text; macromolecules; the monomer library.
- **2026-09-24** (draft): First draft: document structure, molecules and atoms, text, haptic bonds.
