
# Ketcher 3.14.0

## What's Changed

### New features
- [#8352](https://github.com/epam/ketcher/issues/8352) – Introducing rotation of monomers in Macromolecules mode
- [#6917](https://github.com/epam/ketcher/issues/6917) – Support for enhanced stereochemistry markings in macromolecules mode

### Bugfixes and improvements
- [#9113](https://github.com/epam/ketcher/issues/9113) – The Copolymer S-Group type should not be displayed unless there are at least two structural repeating units (SRUs) in selection
- [#9108](https://github.com/epam/ketcher/issues/9108) – Incorrect valence for nitrogen
- [#9126](https://github.com/epam/ketcher/issues/9126) – Some keyboard shortcuts don't work on Macromolecules canvas
- [#8187](https://github.com/epam/ketcher/issues/8187) – It is possible to create preset with empty name
- [#8896](https://github.com/epam/ketcher/issues/8896) – Unable to load KET file in Molecules mode
- [#9328](https://github.com/epam/ketcher/issues/9328) – Migrate to Indigo v1.42.0 in-browser module
- [#9327](https://github.com/epam/ketcher/issues/9327) – Update the help document (3.13.)

---

### Additional notes:
- Ketcher 3.14.0 has been built and tested with Indigo version 1.42 ([standalone](https://www.npmjs.com/package/indigo-ketcher/v/1.42.0) and [remote](https://hub.docker.com/layers/epmlsop/indigo-service/1.42.0/images/sha256-02279a8d696163a2d3ede0f802ec68d878ac2048e43605f8edce2ccf0dadbeaf)).
